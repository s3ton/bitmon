# bitmon

**bitmon** is a browser-first creature-collection RPG set on a 1:1 representation of Earth, with a stylized 2.5D top-down world.

The geographic base uses OpenFreeMap and MapLibre. The game adds original architecture, characters, and creatures. Progression is local-first and verifiable with permissionless trainer registration, public randomness, restricted creature swaps, and player-led gyms.
