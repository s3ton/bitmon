# Instructions for Coding Agents

Before making changes in this repository, **read and follow [skill.md](skill.md)**. It is the mandatory engineering policy for all agents.

Key rules: keep **only fundamental automated tests** and review existing tests before adding any; never commit or retain dead code; simplify previously written code as well as new code; work on short-lived branches created from `preview`, and submit pull requests **targeting `preview`**. Never push directly to `preview` or `main`.

For product behavior, follow [Product Requirements](docs/PRODUCT_REQUIREMENTS.md); for implementation status, follow [Development Tracker](docs/DEVELOPMENT_TRACKER.md).
